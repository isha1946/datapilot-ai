# Design Decisions

## Why I chose this approach

I chose React with Vite because it provides a fast and simple
development setup for building a modern interactive web interface.

For the DataPilot AI landing page, I used a dark visual theme with
purple accents to create a modern AI/data-product appearance.

The page is divided into clear sections:

- Navigation
- Hero section
- Product/dashboard preview
- Features
- How it works
- Call-to-action
- Footer

I used CSS Grid and Flexbox to create the layouts and added responsive
breakpoints so the interface works on both desktop and mobile screens.

## One trade-off

I focused on creating a polished product experience and interactive
visual dashboard rather than implementing a real backend or live
analytics system.

The dashboard currently uses sample/demo data. This allowed me to
complete the interface within the assignment timeframe while keeping
the architecture simple.

## AI usage

I used AI assistance during the development process to help with
initial UI structure, React component code, CSS styling, responsive
layout ideas, and debugging.

I personally verified the generated code by running the application
locally in the browser, checking the layout, testing the responsive
390px mobile view and 1440px desktop view, and making changes where
necessary.

The final implementation was reviewed and tested locally before
deployment.
